# Fabry Layer Farm SIM

Aplikasi recording kandang ayam petelur. Frontend statis (HTML/CSS/JS) di GitHub Pages, backend Google Apps Script (REST API) + Google Sheets.

- Isi `js/config.js` dengan URL Web App Apps Script (`/exec`).
- Langkah lengkap: lihat `PANDUAN-INSTALASI.md`.

Struktur: `index.html`, `css/style.css`, `js/config.js`, `js/api.js`, `js/app.js`, `assets/`.
